# 01: Дневной срез + экран «Сегодня»

**What to build:** Пользователь открывает приложение и видит сегодняшний Дневной срез:
шаги (только браслет), сон, расход калорий, съедено (калории + БЖУ при наличии), вес и
состав тела при взвешивании. Данные читаются из Health Connect при открытии/обновлении и
складываются в локальную базу — история накапливается. Логика агрегации — отдельный чистый
модуль без Android-зависимостей, покрытый автотестами, которые гоняются на сервере сборки.
Существующий экран «Отладка HC» сохраняется как диагностический инструмент.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] Экран «Сегодня» показывает числа из реальных Источников на телефоне владелицы
      (Fitdays и FatSecret — сразу; шаги — с приходом Mi Band 10)
- [ ] Шаги: суммируются только записи Источника браслета (com.xiaomi.wear), телефонный
      шагомер игнорируется (ADR-0001)
- [ ] День без записей по показателю отображается как «данных нет», а не как 0
- [ ] Еда: дневные итоги из NutritionRecord (калории + БЖУ при наличии), приёмы пищи
      по отдельности не хранятся (ADR-0004)
- [ ] Повторное чтение того же дня не создаёт дубликаты
- [ ] Автотесты агрегации проходят на сервере без эмулятора
