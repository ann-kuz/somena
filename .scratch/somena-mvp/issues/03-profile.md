# 03: Профиль

**What to build:** Экран настроек с профилем Пользователя: рост, возраст, цель по весу.
Профиль хранится локально и служит контекстом для будущего Чата по данным. Без заполненного
профиля остальное приложение работает.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] Поля профиля сохраняются и переживают перезапуск приложения
- [ ] Разумная валидация (возраст в адекватных пределах и т.п.)
- [ ] Пустой профиль не блокирует остальные экраны
