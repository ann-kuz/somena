# 04: Бэкенд-прокси ИИ

**What to build:** На немецком сервере разворачивается маленький HTTP-сервис: принимает
запрос от приложения, передаёт его в proxyapi (модель Claude Sonnet, имя модели — конфиг),
возвращает ответ. Ключи proxyapi живут только в конфиге сервера. Эндпоинт healthcheck для
проверки живости.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] Healthcheck отвечает без ключей и внешних запросов
- [ ] Тестовый запрос через сервис возвращает ответ модели
- [ ] Отсутствует/невалиден ключ — сервис стартует и внятно сообщает об ошибке
- [ ] Ключ proxyapi не появляется ни в приложении, ни в логах
- [ ] Сервис не хранит пересылаемые данные (нет персистентности запросов)
