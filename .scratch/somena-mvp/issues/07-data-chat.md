# 07: Чат по данным

**What to build:** Пользователь задаёт свободный вопрос, приложение собирает контекст —
Дневные срезы за период вопроса, Самочувствие и профиль — отправляет на Бэкенд-прокси,
показывает ответ и хранит историю диалога. Без сети чат сообщает об ошибке, остальное
приложение работает. Ответы держатся рамки «обрати внимание и спроси врача», диагнозы
не ставятся.

**Blocked by:** 01 (Дневной срез), 03 (Профиль), 04 (Бэкенд-прокси), 05 (Самочувствие).

**Status:** ready-for-agent

- [ ] Вопрос-ответ работает на живых данных владелицы
- [ ] Контекст ответа учитывает Самочувствие и профиль
- [ ] История диалога сохраняется между запусками
- [ ] Без интернета — внятная ошибка, приложение живо
- [ ] Системный промпт удерживает ИИ от диагнозов
