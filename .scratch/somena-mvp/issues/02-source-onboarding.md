# 02: Онбординг Источников

**What to build:** При первом запуске Пользователь проходит чек-лист подключения
Источников: Health Connect установлен и актуален, разрешения выданы, Mi Fitness / Fitdays /
FatSecret реально пишут данные (статус определяется живой проверкой наличия записей, а не
верой в документацию — ADR-0004), показано предупреждение, что история Mi Fitness задним
числом не заливается. Онбординг доступен повторно из вкладки «Ещё».

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] Первый запуск ведёт по шагам чек-листа без тупиков
- [ ] Статус каждого Источника вычисляется по факту записей за последние дни
- [ ] Предупреждение про отсутствие истории у Mi Fitness показано
- [ ] Онбординг можно пройти заново из «Ещё» (после переустановки источника и т.п.)
