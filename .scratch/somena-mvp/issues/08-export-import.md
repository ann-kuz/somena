# 08: Экспорт и импорт

**What to build:** «Настройки → Экспорт» создаёт один версионированный файл со всеми
данными Пользователя: Дневные срезы, Самочувствие, профиль, история чата. На новом
телефоне «Импорт» восстанавливает всё. Формат — основа будущей автокопии на сервер и
«отчёта врачу» (ADR-002).

**Blocked by:** 01 (Дневной срез), 05 (Самочувствие).

**Status:** готово - реализовано в 0.39.0 по спеке 0021 (см.
`.scratch/export-and-import/issues/`), с файлами Медкарты и настройками внутри.

- [x] Версия формата записана в файле
