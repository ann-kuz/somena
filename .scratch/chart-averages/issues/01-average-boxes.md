# 01: Боксы среднего за окно на «Графиках»

**What to build:** Под каждым графиком вкладки «Графики» ряд маленьких
боксов-пилюль цвета серии со средним значения за отображаемое Окно:
«⌀ 1750 ккал» (формат - как у точек графика). Среднее по дням окна, где
значение есть; пропуски не считаются. Порог съеденного учитывается сам:
дни ниже порога пусты в сериях. Серия без значений - бокс «⌀ —»; Тренд
веса без бокса; графики ИИ в Чате - без боксов (выключатель на графике).
Спека 0022, термины «Окно» и «Среднее за окно» в CONTEXT.md.

**Blocked by:** нет.

**Status:** ready-for-agent

- [ ] Ряд боксов после легенды на каждом графике «Графиков»: по пилюле на
      измеренную серию, цвет серии, «⌀ число единица»
- [ ] Среднее по дням с данными: пропуск - не ноль; смена окна и
      перетаскивание пересчитывают
- [ ] Дни ниже Порога съеденного не попадают в средние Съедено, БЖУ,
      Дефицита
- [ ] «⌀ —» у серии без значений; у Тренда бокса нет
- [ ] Графики ИИ в Чате без боксов
- [ ] Тесты среднего в core (пропуски, пустой список, стык с порогом);
      `gradle :app:testDebugUnitTest` зелёный
