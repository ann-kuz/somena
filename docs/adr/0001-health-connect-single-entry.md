# Health Connect — единственная точка чтения данных на телефоне

Все данные, которые хоть кто-то пишет в Health Connect, наше приложение читает только оттуда, а не через прямые интеграции с каждым вендором. Исключений нет: 24.09.2026 выяснилось, что и FatSecret пишет еду в Health Connect (см. ADR-0004).

Почему: Google Fit API отключают до конца 2026, HC — единственная долгоживущая платформа; но вендоры пишут в него произвольно — Huawei Health не писал в HC никогда (мост Health Sync платный и не работает с Huawei ID региона «Россия»), Mi Fitness пишет с v3.37.2 при включённом вручную переключателе, Fitdays пишет (подтверждено проверкой владелицы; в документации Fitdays этого нет). Поддержка Huawei Band 5i исключена из MVP, потому что через несколько недель планируется переход на Mi Band 10.

Последствия: дедупликацию шагов при нескольких пишущих приложениях выполняет наше приложение, а не HC — решено считать шаги **только с браслета** (Mi Fitness), игнорируя записи шагомера телефона: день без браслета честно остаётся днём без шагов; история задним числом из Mi Fitness не заливается — ждём только новые данные; онбординг обязан содержать чек-лист включения источников.
