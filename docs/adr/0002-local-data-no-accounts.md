# Данные живут на телефоне, аккаунтов нет

Приложение однопользовательское: данные каждого Пользователя хранятся локально на его телефоне, серверных аккаунтов и общей базы нет. Перенос на новый телефон — через явный экспорт в файл и импорт из него; тот же экспорт — основа будущего «отчёта врачу».

Почему: приложение «для себя и друзей», а Бэкенд создавался как прокси к ИИ, а не как хранилище. Аккаунты потянули бы за собой регистрацию, приватность чужих health-данных на сервере и многократный рост сложности — при том, что сценарий «поделился с другом» решается установкой APK, а «перешла на новый телефон» — файлом.

Последствия: нет автосинка между устройствами и нет восстановления «из облака» — Пользователь сам отвечает за файлы экспорта; формат экспорта нужно версионировать с первого дня. Решено: MVP — файл по кнопке, автокопия на сервер (в шифрованном виде, по ключ-фразе) — вторая версия поверх того же формата.
