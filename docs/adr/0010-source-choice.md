# Любой Источник Health Connect; при нескольких пишущих выбирает Пользователь

Дополняет ADR-0001 (Health Connect — единственная точка чтения) и меняет его правило
«шаги только с браслета Mi Fitness»: приложение стало универсальным для друзей
владелицы с любыми весами и браслетами.

Решение: приложение работает с любым приложением, которое пишет в Health Connect.
Источники обнаруживаются по факту записей (ADR-0004): скан за 30 дней показывает,
кто писал каждый тип данных, - каталог известных приложений остаётся только
инструкциями онбординга. Хардкод пакета браслета удалён.

Когда один тип данных пишут несколько Источников (шаги с браслета и с телефонного
шагомера, вес с двух приложений весов), Пользователь выбирает один Источник
в настройках («Ещё» → «Источники данных»); группы выбора: Шаги, Сон, Расход, Еда
и «Вес и состав тела» одним Источником. Выбор применяется фильтром чтения
`dataOriginFilter` при следующем «Обновить» и хранится локально. Без выбора
учитываются все Источники: пересечения интервалов шагов схлопываются дедупликацией
с пропорцией по длительности, поэтому полное двойного счёта не возникает, но
точность выше, когда выбран один Источник.

Почему не «самый свежий источник» и не «источник с наибольшим числом записей»:
правильного Источника приложение не знает - браслет друга может писать реже
шагомера, но быть единственно верным. Решение за Пользователем; выбор сбрасывается
сам, когда Источник перестаёт писать.

Последствия: удалённый из телефона Источник остаётся в списке записей HC, но
получает ярлык «пакет» вместо имени приложения. Уже импортированные дни при смене
Источника не пересчитываются задним числом - свежие поля сильнее старых,
пропуски остаются пропусками (спека 0001).
