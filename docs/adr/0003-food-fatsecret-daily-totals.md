# Еда — дневные итоги из FatSecret через бэкенд

Еда — единственный Источник, не идущий через Health Connect: FatSecret в HC не пишет (проверено по документации и help-центру, сентябрь 2026). Решение: остаёмся во FatSecret (привычка, история, русская база продуктов) и забираем из него только **дневные итоги** — калории и БЖУ; хватает владелице, хранить приёмы пищи по отдельности не будем. Забор делает Бэкенд через официальное API FatSecret (OAuth 1.0a, бесплатный уровень 5 000 вызовов/день), приложение получает уже готовые дневные цифры.

Последствия: доступность API для ru-аккаунта не подтверждена документацией — перед строительством этой ветки обязателен короткий прототип-проверка; если она провалится, fallback — переход на Lifesum (подтверждённо пишет еду в Health Connect, тогда ветка еды идёт по общему правилу ADR-0001 и бэкенд для еды не нужен). Смена или закрытие FatSecret API ломает только ветку еды, остальное не затрагивает.
