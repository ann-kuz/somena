# Спека 0020: Самочувствие звёздами и неотмеченные шкалы

## Problem Statement

Отметки Самочувствия вводятся ползунками 0–10. Ползунок неточно попадает
в нужное значение, а главное - он не умеет «не отмечать»: при открытии
редактора каждая шкала уже стоит на 5, и запись дня нельзя сохранить, если
какая-то шкала не оценена. Так честная отметка «не знаю, как оценить сон»
превращается в фальшивую пятёрку, которая идёт на графики и в контекст
Чата по данным как настоящее значение.

## Solution

Шкалы Самочувствия отмечаются звёздами: десять звёзд в ряд, тап по звезде -
оценка «столько-то из 10», тап по уже горящей звезде снимает отметку.
Неотмеченная шкала - контурные звёзды и «—» рядом с названием: она
сохраняется как не отмеченная и остаётся «—» на плашке «Сегодня» (правило
«—» спеки 0002: пропуск, а не ноль). Новый день открывается с тремя
неотмеченными шкалами - подставлять пятёрки больше никто не делает.

Сохранение записи без единой шкалы и без заметки удаляет отметку дня:
«снять всё» - это тоже решение Пользователя. Вечернее напоминание молчит
только у дня с настоящей отметкой.

Неотмеченная шкала - пропуск везде, где день встречается с числами: графики
не рисуют точку этого дня по этой шкале, контекст Чата по данным не
упоминает шкалу ИИ, Разбор таблицы при слиянии не подставляет ноль.

## User Stories

1. Как Пользователь, я хочу отмечать шкалы звёздами, а не ползунком, чтобы
   оценка ставилась одним точным тапом.
2. Как Пользователь, я хочу оставить шкалу неотмеченной, например сон, чтобы
   она сохранилась честным «—», а не фальшивой пятёркой.
3. Как Пользователь, я хочу снять отметку шкалы повторным тапом по её
   звезде, чтобы исправить случайную оценку.
4. Как Пользователь, я хочу записать день только заметкой, чтобы сохранить
   самочувствие словами без цифр.
5. Как Пользователь, я хочу, чтобы неотмеченная шкала не рисовалась нулём
   на графике и не попадала в контекст Чата как значение, чтобы ИИ не советовал
   на основании выдуманных данных.
6. Как Пользователь, я хочу внести часть шкал вручную через Чат по данным,
   чтобы пустое поле означало «не отмечено», а не отказ.

## Implementation Decisions

- `Wellbeing.energy/mood/sleepQuality` стали `Int?`: null - «шкала не
  отмечена». Миграция БД v8 пересоздаёт таблицу `wellbeing` с nullable-колонками
  (SQLite не снимает NOT NULL правкой), прежние значения не меняются.
- Редактор (`WellbeingUi`): по строке на шкалу - название, цифра оценки или
  «—» в цвете метрики (правило цветов метрик из 0002) и десять звёзд.
  Залитая звезда - core-иконка `Icons.Filled.Star`, контурная - самодельная
  `StarOutlineIcon` в `ui/Icons.kt` (extended-пакет не тянем, спека 0001).
  Звёзды делят строку поровну: влезают на узкий экран, растёт тач-таргет
  на широком.
- Запись без шкал и заметки удаляет отметку (`deleteWellbeing`), а не
  сохраняет пустую: пустых отметок не бывает.
- Ручной ввод шкал в Чате по данным: пустое поле - «не отмечено», годится
  запись хотя бы одной шкалы; `manualWellbeingProblem` различает «пусто -
  не отмечено» и «мусор - ошибка».
- Разбор таблицы: новые дни по-прежнему только полными строками (три шкалы),
  частичная строка без существующей отметки отбраковывается - недобор шкал
  из ИИ подозрителен. Слияние с существующей отметкой больше не подставляет
  ноль в неуказанную шкалу: остаётся прежнее значение или «не отмечено».
- Контекст Чата по данным пишет только отмеченные шкалы; у дня из двух
  отметок шкала с одним значением пишется без пары («энергия 7 из 10»).
  Заметка без шкал идёт в контекст заметкой.

## Дополнение (0.38.0): восьмилучевые светящиеся звёзды

Звёзды шкал сменили форму с пятиконечной на восьмилучевую «сияющую»:
4 длинных луча крестом (вверх-вниз-вправо-влево) и 4 коротких по диагоналям
между ними. Форма выбрана из двух вариантов владельцей; длинный крест читается
на тёмном фоне и не превращает ряд из десяти звёзд в кашу.

- Иконки самодельные в `ui/Icons.kt`: `StarBurstIcon` (залитая, отмеченная
  шкала) и `StarBurstOutlineIcon` (контур-рамка: два подконтура под чётным
  правилом заливки, приём контурных иконок Material). Вершины считаются
  формулой (чередование лучей и впадин), чтобы заливка, контур и путь ореола
  рисовали одну геометрию. Core-иконка `Icons.Filled.Star` больше не
  используется, extended-пакет по-прежнему не тянем (спека 0001).
- Свечение - только у горящих звёзд, статичное (правило «свечение - статично»,
  спека 0002): две ступени полупрозрачной обводки по контуру звезды - широкая
  тусклая (ширина 20 единиц, альфа 0.14) и узкая поярче (9 единиц, альфа 0.28)
  - та же техника, что ореол линий графиков. Контурные звёзды не светятся:
  отметка читается по наличию свечения, а не по его яркости.
- Поведение не изменилось: тап по звезде - оценка «столько-то из 10»,
  повторный тап по горящей снимает отметку шкалы; цвет звезды - цвет метрики.
