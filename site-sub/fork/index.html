Репозиторий на GitHub

Сборка

  1. Установите JDK 17 и Android SDK переменная окружения ANDROID_HOME или файл local.properties в корне проекта.
  2. Соберите APK командой gradle :app:assembleDebug
  3. Готовый файл: app/build/outputs/apk/debug/app-debug.apk

Свой бэкенд

Серверная часть на FastAPI лишь передаёт запросы к ИИ и раздаёт этот сайт. Поднимается из папки backend: зависимости из requirements.txt, ключи в файле .env, юнит для systemd прилагается.
