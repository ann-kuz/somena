Настройка

Всё необязательное: Somena работает и без источников, записи можно вносить вручную.

Установка

  1. Скачайте APK из раздела «Скачать» на главной странице.
  2. Разрешите установку из неизвестных источников. Android спросит об этом при открытии файла: это нормально для приложения не из магазина.
  3. Откройте скачанный файл и установите приложение.
  4. Обновления ставятся поверх: скачайте свежий APK и откройте его, данные и настройки сохранятся.

Источники данных

Somena читает данные из Health Connect: настройте те приложения, которыми уже пользуетесь.

Приложения

  • Mi Fitnessшаги, пульс и сон с браслетов Mi Band
  • Fitdaysвес и состав тела с умных весов
  • FatSecretдневник питания: калории и БЖУ

Подойдёт любое приложение, которое пишет в Health Connect. При первом запуске Somena попросит разрешения: выдаются один раз.

ИИ-чат

  • Популярные APIкаталог моделей с ценами, ключ вставляется в приложение
  • Свой APIваш ключ и любой сервис формата OpenAI, Claude или Gemini

Ключ хранится только на телефоне. Чат работает и без настройки: просто не отвечает, пока ключа нет.
