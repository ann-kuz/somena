# Somena

Личный трекер здоровья: шаги/сон/пульс (Mi Band 10 → Mi Fitness → Health Connect),
вес и состав тела (Fitdays → Health Connect), еда дневными итогами (FatSecret → Health Connect),
самочувствие (3 шкалы 0–10 + заметка), графики, ИИ-чат по данным (proxyapi, ключи на бэкенде).

- Словарь проекта: [CONTEXT.md](CONTEXT.md)
- Решения: [docs/adr/](docs/adr/) — Health Connect как единственная точка чтения (0001),
  локальные данные без аккаунтов (0002), еда дневными итогами из FatSecret (0003/0004).
- Спеки: [docs/spec/](docs/spec/) — MVP (0001), дизайн-система «ночная туманность» (0002).

## Скачать приложение (единственный способ)

Открой на телефоне постоянную ссылку — там всегда последняя собранная версия:

**http://77.239.99.15:8787/apk/somena.apk**

1. Открой ссылку в браузере телефона — APK скачается сам.
2. Нажми на скачанный файл; Android спросит разрешение «устанавливать из этого
   источника» для браузера — разреши и подтверди установку.
3. Обновление ставится той же ссылкой поверх старой версии (данные не теряются).
4. Для Чата по данным выбери источник на вкладке «Ещё»: токен приложения от сервера
   Somena (у владелицы) или «Свой proxyapi» - свой ключ и модели ступеней, приложение
   ходит в ИИ напрямую, сервер не нужен.

Проверка живости без телефона: `curl -s http://77.239.99.15:8787/health`.
Если по ссылке 404 — на сервере не запускали сборку, см. следующий раздел.

## Сборка и публикация на сервере (сервер vkbot, 1 ядро / 2 ГБ + swap)

Раздача всегда через один скрипт: он собирает debug-APK и кладёт его по ссылке выше.

```
/root/somena/scripts/build-apk.sh
```

Не собирать APK вручную мимо скрипта и не придумывать другие способы раздачи —
ссылка из раздела «Скачать приложение» должна оставаться единственной правдой.
Первая сборка медленная (зависимости + swap). `gradle.properties` уже ограничивает
память, демон выключен намеренно — не включать без причины, сервер маленький.
