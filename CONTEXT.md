# Somena — контекст приложения здоровья

Личный трекер здоровья для владелицы и её друзей: агрегирует шаги, сон, вес, состав тела и еду, строит графики и даёт ИИ-советы. Рабочее имя — по папке проекта, не утверждено.

## Language

**Health Connect (HC)**:
Системный хаб Android, куда приложения-источники пишут health-данные, а наше приложение их читает. Единственная точка чтения на телефоне (см. ADR-0001).
_Avoid_: Google Fit, «гугловское здоровье»

**Источник**:
Приложение или устройство, откуда приходят данные: Mi Fitness (шаги, пульс, сон), Fitdays (вес и состав тела), FatSecret (еда). Все пишут в Health Connect. Шагомер телефона Источником не является: шагам верит только браслет.
_Avoid_: провайдер, сервис, интеграция

**Пользователь**:
Человек, на чьём телефоне стоит приложение. Каждый Пользователь хранит только свои данные локально; общих аккаунтов нет (см. ADR-0002).
_Avoid_: аккаунт, клиент, подписчик

**Бэкенд**:
Сервер в Германии. Роль — только прокси к ИИ (ключи и доступ из РФ). Данные Пользователей на нём не хранятся.
_Avoid_: сервер (в значении «где живут данные»), облако

**Дневной срез**:
Агрегированные показатели одного календарного дня: шаги, расход калорий, съедено калорий (дневной итог FatSecret), вес и состав тела при взвешивании, Самочувствие. Единица контекста для Чата по данным.
_Avoid_: день, запись дня

**Самочувствие**:
Ежедневная самооценка Пользователя: три шкалы от 0 до 10 (энергия, настроение, качество сна) и свободная заметка по желанию. Локальные данные приложения, в Health Connect не пишутся.
_Avoid_: настроение (оно — лишь одна из шкал), состояние

**Профиль**:
Данные Пользователя о себе: рост, дата рождения, цель по весу. Возраст не хранится, а вычисляется из даты рождения. Хранится локально, служит контекстом для Чата по данным. Может быть пустым.
_Avoid_: настройки (у приложения есть и другие настройки), анкета

**Чат по данным**:
Единственный формат ИИ-анализа: Пользователь задаёт свободные вопросы, ИИ отвечает, видя Дневные срезы. Периодических сводок и отчётов по расписанию нет.
_Avoid_: ассистент, советник, отчёт ИИ

**Экспорт**:
Один файл, содержащий все данные Пользователя. Назначения: перенос на новый телефон, восстановление, будущий «отчёт врачу». Автокопия на сервер — план второй версии, поверх того же формата.
_Avoid_: бэкап, выгрузка

**Тема-туманность**:
Единый всегда-тёмный визуальный язык приложения: почти чёрный фон с фиолетово-синими свечениями, стеклянные карточки, неоновые кнопки. Правила закреплены в спеке 0002; экраны не задают цвета и формы мимо темы.
_Avoid_: тёмная тема (значение системной настройки), скин

**Правило цветов метрик**:
Золото — метрики «поступления энергии» (шаги, съеденное, жиры); фиолет — все остальные и первые серии графиков; синий — вторые серии (углеводы, тренд). Одна метрика один цвет на всех экранах.
_Avoid_: акцентный цвет без привязки к метрике
